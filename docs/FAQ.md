# FAQ - developer-portal

**Q: What problem does this actually solve?**
A: New Service Owners use the service to provision golden-path workspaces across team namespaces, so service maturity is visible before production onboarding.

Pain point: Platform teams answer the same onboarding questions in chat every week.

**Q: Free to run?**
A: Yep. Cloudflare - $0/mo. See `terraform/INFRA_REQUIREMENTS.md`

**Q: Production ready?**
A: Yes - SLOs, security hardening, DR runbook, Helm, Terraform, monitoring.

**Q: Stack?**
A: Backstage, Crossplane, ArgoCD, Kubernetes Operators, Vault

**Q: What infra do I need?**
A: `terraform/INFRA_REQUIREMENTS.md` has the full breakdown - CPU/RAM/storage/network/cost.
